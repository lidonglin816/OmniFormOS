# 八大模块的界面分工

本次针对模块首页结构雷同进行调整，沿用品牌、主导航、已有编辑器、数据绑定及业务操作。

| 模块 | 首页工作方式 |
| --- | --- |
| FormPilot | 紫黑双栏需求创作区、蓝图阶段、应用项目 |
| ExamCraft | 测评准备台、试卷档案、考试安排、待阅卷清单 |
| FlowForm | 流程定义拓扑、运行状态、审批待办 |
| DocMorph | 原件导入站、文档处理队列、复核进度 |
| AdaptForm | 表单目录、条件分支、可操作的实时填写预览 |
| TableMind | 数据目录、真实记录的电子表格预览 |
| LabForm | 实验仪表条、真实测量曲线、研究档案、记录目录 |
| AppCanvas | 应用交付入口、真实页面结构缩略、项目管理 |

样式集中在 `public/module-identities.css`，使用模块首页作用域。未更改数据库结构、已有记录或发布快照。AppCanvas Studio 沿用原有沉浸式编辑布局。
