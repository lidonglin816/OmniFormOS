# AppCanvas 升级与验证

本次基于已有 AppCanvas 修改，其他七个模块的原有页面和数据库保留。旧浏览器草稿、页面 ID、业务绑定及历史发布快照在首次访问时迁移至 `data/appcanvas.sqlite`，另保留原始 JSON 备份。旧模型文件保持兼容，跨模块导入继续使用现有入口。

## 已实现

- 应用设计工作台：多应用、名称搜索、状态筛选、时间排序、模板、空白创建、FormPilot 蓝图导入、复制、配置导出、二次确认删除。
- 沉浸式编辑器：收起平台导航，56px 工具栏，可收起/拖动调宽的左右面板，缩放、适应、100%、中键平移、网格与拖拽参考线、全屏。
- 35 类组件：基础内容、嵌套布局、字段控件、真实数据表/指标/ECharts 图表/看板/日历、导航、审批/考试/实验/数字表单/动态表单、AI 对话及页面内检索。
- 指针拖拽添加、排序和容器嵌套；图层搜索、锁定、隐藏、Shift 多选、文字对齐、组合、复制删除、撤销重做、自定义组件复用。
- 内容、样式、数据、交互、权限五类属性；桌面基础样式和平板/手机断点覆盖；页面增删复制重命名、拖动排序、自定义路由、页面权限、主题、公共页头页脚。
- AI 通过已配置的兼容接口返回结构化页面 Schema，校验后先展示候选差异，确认应用或取消；不执行模型返回的代码。AI 对话仅使用配置的可公开字段作为数据依据。
- 实时数据读取复用 TableMind、FlowForm、LabForm 服务；FormPilot 导入实体通过现有 TableMind 同步接口接入并保留来源应用 ID；DocMorph/AdaptForm 复用原来的已发布表单运行时；ExamCraft 复用学生邀请码和原有考试权限。
- 字段选择、包含筛选、排序、计数/总和/平均值。业务表单执行真实 TableMind 校验并写入原表，可配置启动已发布 FlowForm 流程。审批启动失败时明确提示数据已保存而审批未启动。
- 服务端版本快照、草稿冲突检查、恢复版本到草稿、发布前检查、访客角色过滤、公开/密码/仅工作区访问。恢复草稿不会改变在线发布版本。
- 编辑/预览/正式运行共用渲染器；预览可模拟角色；正式链接忽略客户端传入的管理员角色。控制台记录数据请求与错误。

## 当前边界

- 当前平台运行在 127.0.0.1，本次未部署公网，也未新增跨互联网的统一账号/组织登录。管理员设计 API 仍沿用现有本地工作空间信任边界，不能直接作为多租户公网服务开放。
- AI 需要配置 OMNIFORM_AI_BASE_URL、OMNIFORM_AI_API_KEY、OMNIFORM_AI_MODEL。未配置返回明确错误，不使用固定示例冒充生成。
- 当前为流式布局与 CSS Grid 嵌套编辑，拖入时按组件边界排序吸附；未实现自由绝对定位、旋转、像素级尺寸拖杆或任意图形设计。
- 独立字段控件可交互；真实记录提交通过绑定数据源的“业务表单”。独立文件选择控件明确提示仅选择文件，尚无独立附件存储服务。需要附件提交时使用 DocMorph/AdaptForm 已有表单运行时。
- 审批组件读取真实任务状态，审批决策继续在 FlowForm 原模块操作；本次没有复制审批鉴权实现。ExamCraft 学生验证、计时和评分保持使用原模块。
- FormPilot 原数据仍沿用原有本地存储，导入时同步为 TableMind 实体；之后应用运行读写 TableMind 原表。没有宣称对浏览器关闭后的 FormPilot 本地数据进行后台持续同步。

## 验证

单元与接口测试覆盖旧版本迁移、嵌套副本 ID、路由与类型校验、内容转义、角色过滤、查询计算、SQLite 冲突、不可变发布快照、真实 TableMind 新增、字段越权阻止、密码访问、私有访问、AI 兼容协议、无模型错误、恢复草稿不影响在线版本。

浏览器实际完成：创建“实验数据门户”→添加横幅→编辑文字→绑定 LabForm 六条既有实验记录→增加 analysis 页面→配置真实折线图→预览→检查并发布→访问链接→页面跳转；验证拖拽添加、撤销重做及自动保存。

示例应用没有修改现有测量记录。发布页面的平均电压来自复用 LabForm 确定性计算引擎。新增提交测试使用隔离的内存数据库。
