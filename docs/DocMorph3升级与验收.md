# DocMorph 3.0 升级与验收

验收日期：2026-10-24。

## 已实现

- 原文、字段审核、可填写表单三栏工作室；独立滚动、宽度调节、折叠、全屏与移动端堆叠。
- PDF 原生文字及坐标、原生填写控件、DOCX 文本、XLSX 单元格、图片与扫描 PDF 本地 OCR；文件签名校验。
- 字段来源定位、类型与规则修改、人工确认填写区域、审核筛选与批量确认、修改历史。
- 关键词/数值/日期提取规则、原文规则候选、已确认映射模板；模板不保存原件业务值。
- AI 修正候选展示差异并确认后应用；校验来源和文档修订，未配置模型时明确失败。
- 多文件顺序任务、真实状态、保存原件后失败重试、结构化结果导出。
- SQLite 保存文档、原件、任务、模板和版本；浏览器副本迁移、并发修改冲突保护和本地恢复副本。
- 表单发布、真实填写提交、服务端校验、提交记录搜索、按筛选导出 CSV/XLSX。
- 重新排版的交互式 PDF；原 PDF 在逐字段确认坐标后添加填写控件，旋转页面会明确拒绝。
- AdaptForm 草稿、TableMind 数据表、FlowForm 审批草稿的真实服务端联动。
- 文档、任务、模板、发布表单和提交记录接入统一测试与数据管理及回收站。

## 验证结果

- `npm test`：192 项通过，0 失败。
- `npm run check` 和 `npm run build`：通过。
- 原生 PDF 解析脚本：1 页、8 个字段，均有来源坐标。
- PDF 原件区域回填测试：页面尺寸保持、必填与控件坐标正确，未经人工确认的区域拒绝导出。
- 真实浏览器、独立 3400 端口数据库：上传 PDF → 完成任务 → 8 字段批量确认 → 发布 v1 → 公开表单提交成功 → 重新加载显示 1 条记录。
- 浏览器原件预览完成绘制，显示“原始 PDF · 第 1 页”，无错误级浏览器日志。
- 浏览器实际宽度 429px，验证了窄屏堆叠布局；当前内嵌浏览器未应用 1440px 视口覆盖，因此不声称完成桌面宽屏视觉验收。
- 测试数据保留在 `artifacts/docmorph3-qa-*.sqlite`，没有写入主应用数据库。
- 已生成工作空间备份 `artifacts/docmorph3-workspace.ofbackup`。

## 当前边界与后续工作

- 复杂跨页表格、手写及复杂版式仍需人工核对；DOCX 提供提取文本，不还原 Word 原始分页。
- 当前 OCR 为本地文字识别；未接入额外云端多模态文档服务。
- PDF 离线填写不会自动提交，也不执行在线条件规则；附件通过在线表单上传。
- 原 PDF 添加控件需要人工指定填写区；已有表单控件的原件需检查重叠位置。
- FlowForm 联动生成带来源的审批草稿，需配置审批人及复杂条件后发布；尚不支持 DocMorph 提交自动触发该审批。
- LabForm、AppCanvas、FormPilot 的专用业务应用生成，以及 DocMorph 内嵌重复子表设计器尚未实现。不要将这些列为已验收能力。
