# 测试与数据管理

入口：八大模块顶部的“测试与数据管理”；AppCanvas 编辑器顶部提供“数据管理”。也可访问 `/workspace-data.html`。

支持：模块/记录类型/测试标记/关键词筛选；本页或全部筛选结果选择；单条或批量移入回收站；单条或批量恢复；批量标记为测试或正式业务。每批最多500条，列表每页40条。

管理范围：

- ExamCraft：考试、答卷、试卷、题目、来源。
- FlowForm：流程定义、运行记录、隔离测试、申请草稿。
- DocMorph：已进入数据库的数字表单和提交记录。
- AdaptForm：表单与提交记录。
- TableMind：数据表、数据记录、视图、仪表盘、查询记录。
- LabForm：实验项目、模板、测量记录、实验报告。
- AppCanvas：应用、自定义组件。
- FormPilot：业务项目、最近一次持久化测试结果。

“疑似测试”只依据名称提示，不自动修改或删除数据。显式 mode=test、隔离测试及 FormPilot 测试结果标为测试。手工测试标记只用于管理分类，不重写评分、审批状态或统计口径。

删除采用回收站：原记录快照写入所属模块 SQLite 的 workspace_trash，并保留操作审计。完整工作区备份会一起包含回收站。没有永久清空操作。

考试/流程管理继承各自教师/工作区会话。没有会话时点击“打开对应模块”，建立会话后返回刷新。管理接口同时要求本机工作区会话，拒绝跨站写入。

正在进行的考试/审批、存在未处理引用或跨模块绑定的数据不能直接删除，需先结束、撤回或解除依赖。批量操作在单模块事务中执行，任何一项失败都不会部分删除。恢复自动优先恢复父记录，ID冲突、父记录缺失及数据唯一校验冲突会阻止覆盖。

管理页面在独立标签页打开。操作后请刷新原模块以显示最新记录；服务端统计和共享视图从更新后的数据库计算。浏览器内尚未发布的旧版文档原稿不属于该数据库管理页，继续通过原文档工作台管理。

验证：新增8项服务回归（覆盖八模块），总计165项测试通过；语法检查通过；隔离浏览器实测2条记录批量删除及批量恢复成功。验收截图 artifacts/workspace-bulk-management-verified.png 使用3300隔离实例的非正式样本；正式工作区记录没有被自动删除。
