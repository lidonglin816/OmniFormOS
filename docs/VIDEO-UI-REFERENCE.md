# 视频参考 UI 调整

参考用户提供的本地视频 `aa2321ca47.mp4`（140.77 秒）。关键画面已提取在 `artifacts/video-reference/`。

## 采用的视觉与交互

- 2、50、70 秒：彩色实体感卡片、扇形排布、悬停抬起与邻卡让位。
- 10、90、115 秒：深色展览背景、醒目的标题、克制的导航与编号。
- 20 秒：避免以重复紫色渐变和发光卡片作为全部页面的设计语言。
- 视频包含多个独立案例；本项目将共同特点转化为业务 SaaS 的官网展示和工作台界面，没有声称安装视频作者的 Skill。

## 实现范围

`public/app.js`：首页结构、八个真实引擎跳转入口、保留原需求表单及事件处理。

`public/creative-system.css`：官网深色画廊、八种配色的 CSS 立体造型、空间悬停、触屏横向卡片浏览、键盘焦点和减少动态效果适配；工作台与创作中心统一细节，专业业务编辑器继续使用浅色表面与各自布局。

未更改业务数据、API、数据库结构或发布快照。立体造型为项目内 CSS 元素，无新增第三方图片或运行依赖。

## 验证

- 111 项自动化测试通过；语法检查、生产资源构建通过。
- 8 个模块页面实际加载，1265px 可用宽度下均无页面级横向溢出。
- 卡片点击能够进入 DocMorph 现有工作区。
- 手机 375px 可用宽度：页面滚动宽度也是 375px，八张卡片在独立区域横向浏览。
- 浏览器未捕获控制台错误。
- 未重新手工执行全部业务创建、审批或考试流程，相关保护来自现有自动化测试。
