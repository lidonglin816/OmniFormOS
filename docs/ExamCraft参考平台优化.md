# ExamCraft 参考平台优化

2026-10-22。本轮在原有考试和分析系统上增量修改，保留数据、试卷快照及访问权限。

## 本轮交付

| 参考方向 | 优化结果 | 入口 |
| --- | --- | --- |
| QuestionWell：学习目标、选题审核 | 出题表单增加学习目标；知识点待审数量与筛选；解析、原文引文、重复选项初检 | AI 智能出题、智能题库 |
| Testportal：生成后复核 | 质量提示显示在编辑器顶部；生成仍进入待审核队列 | 智能题库 |
| ClassMarker：完整考试流程与作答状态 | 考试卡片增加进度入口，查看作答数量、最近保存、状态并钻取答卷；保留原有邀请、服务端计时、标记和交卷确认 | 在线考试 → 进度 / 逐题诊断 |
| Formative：过程反馈 | 每 8 秒刷新已保存答题记录，投屏时可隐藏姓名及编号 | 考试诊断 |
| Easy LMS：选项级分析 | 每道题显示正确率、评分样本、待批阅数及选项选择人数 | 考试诊断底部 |
| Quizgecko：考后针对性复习 | 从本人已确认错题建立练习，提交后显示参考答案及解析，数据库单独保留最近 30 轮摘要 | 考生答卷提交页 → 错题重练 |
| Kahoot! / Wayground：清晰进度和学习反馈 | 练习选项选中态、回答结果与完成反馈，保留正式考试的稳定节奏 | 考生练习页 |

## 统计与权限

- 教师诊断接口检查教师会话，不返回答卷密钥或邀请代码。
- 正确率只包含该题已确认评分；选项人数只统计已提交答卷，多选可重叠，不将待批阅视为零分。
- 考试结束或关闭而未开始的名单记录标为缺考。
- 考生练习必须持有本人答卷令牌、完成整卷评分，且考试已结束或关闭。
- 仅允许本答卷已评分失分题；重新作答不修改正式答案、总分和分析指标。
- 简答及计算题需要对照解析自评，不伪装成 AI 判分；练习题目取原答卷快照，不冒充新生成题。
- 进度反映已保存答案，并非实时在线监控。隐藏姓名是展示功能，不替代教师访问权限。

## 界面修改

| Before | After | Why |
| --- | --- | --- |
| 只能用搜索与分类查找待审题 | 知识点筛选及待审数量 | 审核更聚焦 |
| 编辑器需自行逐项检查 | 显式展示初检提示 | 降低漏审 |
| 考试卡片仅展示汇总人数 | 进度、明细及逐题诊断 | 贯通过程与结果 |
| 考后练习只是展示参考题 | 可重新作答并检查结果 | 形成真实复习操作 |

保留共享导航动效、浅深色主题；知识点按钮仅短颜色过渡，支持减少动态效果。诊断轮询仅更新内容区域，不重绘整个工作区。

## 验证

180 项自动测试通过。新增测试覆盖：进度统计、选项分布、待批阅口径、教师权限、本人隔离、考试结束限制、非法答案、练习不改写正式成绩、质量提示。语法检查与资源构建通过。浏览器验证知识点筛选、诊断加载、隐藏姓名。

## 范围说明

未实现多人同步抢答、实时排行榜、完整间隔复习调度、证书系统；本轮没有接入外部网站账户或复制其数据。AI 生成与 AI 解读继续要求配置真实模型服务。Wayground 官网文本访问被机器人验证拦截，因此不将其付费功能或内部布局作为已实测事实。
