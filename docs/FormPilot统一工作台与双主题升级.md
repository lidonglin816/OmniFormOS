# FormPilot 统一工作台与双主题升级 — 2026-10-22

本轮按用户提供的产品研究抽取设计要求，复用原有引擎，未另建一套页面或审批模型。

## 已落实

1. 浅色 / 深色：所有主页面和公开运行页面增加切换入口，右下角可直接切换；“界面选项”中也可选择。localStorage 保存选择，刷新时在首屏绘制前加载，多标签和同源嵌入编辑器同步。图表同步坐标、图例、Tooltip、雷达、缩放和背景，不改统计值。
2. 业务蓝图：创建前可编辑实体名称，新增/删除实体和字段，设置类型、必填、默认值、选项、关联目标；配置页面名称、类型与是否生成。ID 保留。多对多使用中间实体，不声称已经实现任意关系推断。
3. 统一可视化设计：App Studio 的“可视化设计”直接使用已绑定 AppCanvas 的同一应用、页面、组件与数据源。支持原有内容/布局/样式/数据/交互属性、图层选中和桌面/平板/手机断点。
4. 局部组件上下文：画布选择同步 Copilot，消息校验同源、iframe来源与绑定应用ID。组件计划由后端重新查找组件，客户端不能传入陌生应用组件执行修改。
5. 任务模式：全栈、数据建模、UI设计、工作流、调试修复。数据模式限定实体与字段；UI模式限定选中组件文本与安全样式；工作流复用 FlowForm 的候选审核和编辑器；调试调用真实 Test Lab 并显示结果。没有宣称这些入口都是已配置的全自主 Agent。
6. 修改确认与恢复：设计候选先预览、再确认写入共享画布。拒绝过期画布计划，保留30条组件设计历史，可精确恢复；不改变其他组件或数据记录，不修改正式发布快照。画布更新后发布前必须重新测试。
7. 可解释运行：真实构建步骤持久化后供进度查询，不显示虚构百分比。真实运行请求记录操作、状态、实体和耗时；隐藏请求正文、密码与令牌；可定位数据实体。只向设计工作区返回运行日志。
8. 数据安全修复：深链接打开绑定画布不会被匿名旧版种子草稿覆盖；已有草稿版本落后时保留本机恢复副本，不自动覆盖服务端。局部数值样式输出px，明确设计颜色保留在组件样式中。

## 使用流程

进入 FormPilot → 创建或打开项目 → 复核业务蓝图 → 构建应用 → App Studio“可视化设计” → 点击组件 → 任务模式选UI设计 → 输入修改 → 生成计划 → 确认应用。需高级属性时直接使用右侧 AppCanvas 属性面板。

无模型凭据时，本地UI指令支持：`正文改为新的欢迎语`、`标题改为新的名称`、`内边距24`、`圆角12`、`字号18`、`背景色#abcdef`。复杂语义修改需选择AI并配置真实服务；无法支持的本地指令明确报错，不伪造完成结果。

组件设计改动会生成独立历史。蓝图仍使用原有草稿版本/差异与发布管理。运行日志是请求元数据，不是任意数据库SQL或系统源码控制台。
