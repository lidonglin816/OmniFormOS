# AdaptForm 3.0 升级与验收

日期：2026-10-24。保留历史 SQLite 数据、原发布快照、现有七个模块和主题切换。

## 从现状到本次实现

| Before | After | Why |
| --- | --- | --- |
| 工作台长期同时展示规则和表单 | Hub 管理与 Studio 编辑分离，八个功能入口 | 聚焦当前操作 |
| 重复组预览有占位按钮，正式页另写渲染 | 预览与正式页使用同一渲染组件，真实增删子字段与人数限制 | 保证操作有效且行为一致 |
| 规则只处理平面 AND/OR 和双操作数 | 嵌套条件、NOT、动态选项、填充、计算、跳转、跳过、结束文字与重复组限制 | 覆盖实际校园场景 |
| 规则画布是规则卡片 | React Flow 独立画布，拖动、缩放、搜索、双击编辑和连接规则到字段 | 地图与规则列表共用一份 Schema |
| 无访问采集与分析 | 实际浏览会话、开始、步骤、提交事件，六类 ECharts 图表 | 不从提交量伪造访问统计 |
| CSV 导出只在前端且未应用当前搜索 | 服务端按搜索/日期筛选导出 CSV/XLSX，并保留历史版本字段 | 导出范围与统计依据可解释 |
| 编辑依赖手动保存 | 防并发覆盖的自动保存、撤销重做、冲突恢复副本 | 不丢失请求期间继续编辑的内容 |

## 已实现的使用流程

1. 工作台搜索、状态筛选、最近编辑/名称排序、复制、重命名、归档；删除与批量操作接入统一回收站。
2. 三栏字段设计器：组件库、页面结构与画布、字段属性；添加、复制、排序、拖动、删除、字段类型修改、半行/整行宽度、默认值、校验。支持 `/数字` 等快捷插入。
3. AI 新建或增量修改经过 Schema 校验，展示字段与规则差异，确认后保存；过期候选拒绝应用。未配置模型时明确提示，不生成伪造 AI 结果。
4. 规则执行无 eval；动态结果收敛后提供条件、动作、字段状态、路径与计算错误。计算支持加减乘除、sum/average/min/max/percent/dateDiff/count/sumRows/if。
5. 预览包含桌面、平板、手机模式；自动生成的测试场景使用真实引擎执行。场景触发比例明确不等同于测试覆盖率。
6. 公开或本机工作空间受限填写；发布快照与草稿分开，截止时间、总提交上限和同浏览器会话限次由服务端执行；支持关闭、重新开放、历史版本恢复、成功页文字和强调色。
7. 独立填写页可显式保存/恢复本机草稿，附件需重新选择；版本不一致时不自动套用旧草稿。成功提交清除草稿。
8. 二维码可下载 PNG；本机 127.0.0.1 地址不会冒充跨设备公开部署。
9. 真实数据图表：提交趋势、会话状态、选项分布、步骤到达人数、规则路径、填写时长。支持日期筛选、选项切换、Tooltip、缩放、全屏、PNG 和深浅主题。无数据明确说明；少于 10 条提示样本不足。分析页每 30 秒刷新，编辑筛选时暂停刷新。
10. 十个校园模板；重点完成竞赛团队报名、费用明细汇总、设备借用日期计算三个复杂场景。

## 数据与访问策略

- 浏览量是访问会话数，不是独立自然人数。开始数由用户交互事件采集。
- 完成率分母是实际开始填写的会话，分子是这些会话中已成功提交的会话；历史没有会话的记录仍计入提交量，不推算访问与耗时。
- 答案搜索仅作用于提交记录；访问漏斗按日期计算，界面明确说明这一统计范围差异。
- 隐藏值默认清空；选择保留时，只用于本机继续填写/条件计算，不进入正式业务记录。重复组未知子列也不进入业务记录。
- 服务端重新计算计算字段，不信任客户端传来的计算结果；附件必须包含与声明大小一致的实际内容。
- 公开 Schema 删除发布快照、历史、绑定和文档来源；管理与分析接口使用本机工作空间会话。
- 已删除表单的旧编辑窗口不能自动保存并复活该表单，必须通过回收站恢复。

## 跨模块

- DocMorph：沿用已实现的服务端 AdaptForm 草稿导入，保留字段来源与 ID。
- FlowForm：界面选择已发布流程并配置字段映射；成功提交后立即同步审批事件，已有未处理记录也会同步；相同绑定更新映射，不重复添加绑定。失败事件由 FlowForm 查看和重试。
- TableMind：真实提交同步等待服务端完成后才提示成功。
- AppCanvas：创建带真实已发布表单 runtimeToken、formId/version 来源的嵌入草稿；未替用户自动发布微应用。
- ExamCraft 评分逻辑未改动。FormPilot 与 LabForm 的专用自动生成/复杂业务配置器未在本轮扩展，不能将其称为已完成的新联动。

- `npm test`：200 项通过，0 失败；`npm run check`、`npm run build` 通过。
- 自动化覆盖：十个模板 Schema、团队人数与未知子列过滤、求和与日期差、嵌套 NOT、动态选项、隐藏保留策略、真实访问/开始/完成率、CSV/XLSX、访问限制、截止时间与数量上限、伪造文件拒绝、自动保存过程中继续编辑及存储版本推进。
- 集成测试：真实 AdaptForm 提交立即生成一个 FlowForm live 审批，再次同步不重复创建。
- 浏览器（独立 3400 端口）：创建竞赛模板 → 团队预览 → 增删成员 → 逻辑地图 → 发布 v1 → 正式团队填写 → 保存本机草稿 → 刷新恢复 → 成功提交 → 后台统计显示 1 浏览/1 开始/1 提交 → 下载真实 XLSX。
- 浏览器修改重复组上限为 6，预览显示 6 人上限，保存和刷新后仍保留。修复了隐藏控件 `name="id"` 遮蔽 DOM 表单 ID 导致属性提交失效的问题。
- 浏览器验证二维码显示、可下载，以及 AppCanvas 嵌入草稿创建成功。
- 主数据库保持原路径；考试继续使用 `artifacts/exam-analytics-ui.sqlite`。测试数据保留于 `artifacts/adaptform3-qa-*.sqlite`。
- 升级前工作空间数据库备份：`artifacts/before-adaptform3.ofbackup`。

## 仍需明确的边界

- 高级嵌套条件、复杂计算和重复组子字段使用结构化 JSON 属性编辑；地图已支持节点定位与规则到字段的连接，但尚非任意节点类型的无代码连线编排器。
- 当前布局支持页面和字段分栏；未实现任意嵌套布局容器、图片自由排版或拖拽新建容器。
- 草稿续填保存在当前浏览器，未提供跨设备云草稿或附件续传。
- 同会话限次不能防止换设备或清除浏览器会话；受限填写沿用本机工作空间，尚无多租户账号成员体系。
- 未配置外部 AI 时，只能使用手动设计或模板；本轮没有以模板冒充 AI 实际生成结果。
- 手机预览与窄屏 CSS 已实现，未声称经过真实手机硬件验收。

主应用入口：`http://127.0.0.1:3100/#adaptform`。
