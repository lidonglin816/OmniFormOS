# 桌面端参考图 UI 升级

2026-10-24，桌面包版本 1.1.0。沿用用户参考图的布局，保留 OmniFormOS 品牌和现有业务入口。

| Before | After | Why |
| --- | --- | --- |
| 网页营销首页直接装进窗口 | 浅灰侧栏、圆角主工作区、点阵背景 | 使用参考图的桌面工作台结构 |
| 大幅营销内容和八个立体卡片 | 居中标题、大输入框和分类快捷按钮 | 让需求输入成为主要操作 |
| 系统标题栏加常驻菜单 | 原生窗口控制叠加标题栏，菜单通过 Alt 使用 | 减少顶部视觉负担，保留系统操作 |
| 首页缺少项目侧栏 | 四项常用导航、真实项目列表、主题与设置 | 让创建、继续工作和设置更直接 |
| 桌面样式与网页共用 | preload 标记桌面环境，CSS 仅在桌面生效 | 保留浏览器首页，不改动八模块业务逻辑 |

## 功能连接

- 输入框沿用原有需求生成表单，生成可编辑应用草稿；不冒充已配置在线模型。
- 文档按钮进入 DocMorph；AI 工作台入口进入 FormPilot。
- 五个快捷按钮加三个次级入口覆盖八大模块。
- 最近项目来自当前浏览器分区的真实应用列表；未伪造对话记录。
- 侧栏可收起/展开并记忆状态。主题使用既有主题系统。
- 设置按钮通过受限 preload 打开桌面数据目录，主进程校验来源。
- 内部页面继续保留原有导航和功能，桌面外框统一圆角和背景。

## 验证

238 项既有及桌面测试通过。新 JS、preload 和主进程语法检查通过。原生窗口中检查了首页侧栏、项目入口、需求输入和全部八模块入口；修复了全局 main 宽度和内部侧栏偏移对新布局的影响。

浅色实际窗口截图：`artifacts/desktop-ui-light.png`。截图中操作系统的桌面宠物悬浮层不是本项目内容。

安装包：`output/desktop/OmniFormOS-Desktop-1.1.0-x64-Setup.exe`。应用数据目录和原有备份保持不变。桌面原生菜单可按 Alt 呼出。
