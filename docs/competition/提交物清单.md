## 本地验证命令

```powershell
npm install
npm run check        # 130+ 文件语法检查
npm test             # 单元测试
npm run dev          # 网页端 3100
npm run desktop      # 桌面端开发窗口
npm run desktop:build  # 重新打包桌面安装包
npm run desktop:sync   # 同步到本机已安装副本（单一真源）
```
