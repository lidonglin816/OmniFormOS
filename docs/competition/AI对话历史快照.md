## 链路一：SaaS 登录系统重构（认证体系落地）

**Prompt 1（需求规范输入）**

> 按 Premium SaaS 规范（参考 Linear / Vercel 英文风格）重构登录系统与个人中心：需要 Sign in / Sign up / 6 位邮箱验证码（60 秒冷却）/ 找回密码 / 重置密码 / 账户中心（Verified 徽章、主题切换、登出）。密码使用加盐 SHA-256 存储，禁止明文。

**Prompt 2（功能补充）**

> 界面设置语言功能放到设置中。

**Prompt 3（Bug 引导修复）**

> 登录页的 Google 按钮是假的（截图反馈）。删除 Google 按钮、分隔线、对应报错分支和图标，不要保留任何假入口。

**结果**：产出 `omni-auth.js/.css`，本地认证 + 设置 + 双语支持，验证码流程完整；移除未实现的第三方登录避免评审误判。

## 链路二：全局双语 i18n 引擎（跨模块翻译）

**Prompt 1（需求）**

> 语言切换要生效针对所有界面，不只是登录页。

**Prompt 2（Bug 反馈 1）**

> 我的八大功能模块中还有些地方没有切换成英语，全面核查。（附截图标注残留位置）

**Prompt 3（Bug 反馈 2，深挖）**

> 每一个模块点进去的小模块仍有问题，把项目一层一层地核查。（附二级页面截图：可见"可视化编辑器复用现有 React Flow"等中英拼接文本）

**AI 诊断与修复过程**：
1. 定位为词典缺失 + 动态渲染文本绕过翻译 → 补充 `omni-i18n-extra.js` 深层词典约 500 条
2. 发现 `translate=no` 标记导致动态业务数据被整体跳过 → 放宽过滤规则
3. 发现 ES 模块磁盘缓存加载旧词典 → 给翻译模块与入口加版本号强制刷新
4. 编写 CDP 自动巡检脚本遍历 150+ 子页面入口，将中文残留清零

**结果**：全局 DOM 级翻译引擎 + 约 2000 条词典 + MutationObserver 动态翻译，中英一键切换。

## 链路三：大模型 API 接入与模型切换 UI

**Prompt 1（需求）**

> 项目里有的模块需要接入模型。查一下我桌面上 Modex 的模型配置，模仿它接入大模型 API。

**Prompt 2（迭代）**

> 设计成可以自由切换模型的 UI 界面，类似于 Modex。

**AI 执行过程**：
1. 读取本机 `~/.codex/config.toml` 与 `switch_codex.py`，提取 4 个上游方案（official/mhcode/yuntu/sub2api）
2. 实测各上游：MHCode key 欠费；云途 `gpt-6.1-sol` 出题超 60s 撞网关 504；换 `gpt-6-astra` 21 秒成功
3. 新增 `src/ai-config.mjs`（GET/POST `/api/ai/config`），配置持久化到用户目录并热应用到各模块
4. 设置面板加服务商预设芯片 + 地址/模型/密钥编辑 + 保存即生效

**Bug 修复链**：
> 保存后状态提示被整体重渲染冲掉了 → 改为局部更新状态卡，不再整页重绘。

## 链路五：深色主题视觉 Bug 修复系列（引导 AI 定位 CSS 优先级冲突）

**Prompt 1**
> 深色主题下窗口左上角红绿灯没有颜色了。（附截图）

**AI 诊断**：`dark-fix.css` 中全局 `button { background: … !important }` 覆盖了红/黄/绿专用色 → 提高三颗按钮选择器优先级修复。

**Prompt 2**
> 侧边栏显示颜色与背景不匹配。（附截图）

**AI 诊断**：深色主题全局规则把所有导航项染成蓝紫色，看起来全部处于选中态 → 统一为中性石墨黑层级（`#171b23` 背景 / `#202630` 悬浮 / `#292f3b` 选中），普通项透明化，仅保留当前项紫色指示线。

**Prompt 3**
> 主页文本框里面的颜色与主题背景不搭配。（附截图）

**AI 诊断**：通用 `input,textarea` 深色规则把创作框染成蓝紫色 → 为 `.desk-composer` 建立独立中性配色层（输入面 `#1b2029`、边框、占位文字、模型选择器、发送按钮同步调整）。

## 核心协作模式总结

| 模式 | 应用场景 |
|---|---|
| 规范先行 | 登录系统：先给完整英文 SaaS 规范再实现，减少返工 |
| 截图驱动 Bug 修复 | 主题冲突系列：截图标注 → AI 定位根因（CSS 优先级/缓存/残留引用）→ 修复 → 实机复验 |
| 真实数据实测 | AI 接入：实测 4 个上游的余额与延迟后再选型，而非照搬配置 |
| 自动化巡检 | i18n：CDP 脚本逐层扫描代替人工目测，150+ 入口清零 |
| 变更即验证 | 每次修改后语法检查 + 实机截图 + 双部署（安装版/开发版）一致性校验 |
