## 第 1 步：录视频（对着《演示视频录制执行清单.md》走）

1. **录前 5 分钟**：启动安装版 → 设好 ExamCraft 教师密码（设置里点一次即可）→ 关壁纸软件/QQ 弹窗 → OBS 设 1920×1080 / 30fps / 8-10Mbps
2. **录屏**：按执行清单 11 个镜头照着点，AI 协同两段（3:30-5:55）必录且不可剪
3. **剪辑**：剪掉等待/误点，等待段压 1.5x；导入 `演示视频字幕-中文字幕.srt` 做硬字幕；导出 H.264 MP4
4. **自查**：清单末尾 8 条扣分点逐条打勾，确认时长 6:30-7:30
5. **命名**：`OmniFormOS-演示视频-团队名.mp4`

## 第 2 步：建仓库并推送

**选 GitHub 或 Gitee 二选一**（Gitee 国内访问快，GitHub 国际评审友好；时间够就两边都放）。

在 gitee.com / github.com 网页上新建**公开**仓库（不要勾选初始化 README），然后在项目目录执行：

```powershell
cd "C:\Users\LiDongLin\Desktop\OmniFormOS 8合1 旗舰方案AI 原生全场景低代码应用生成与智能业务自动化平台"

# Gitee
git remote add origin https://gitee.com/<你的用户名>/omniformos.git
# 或 GitHub
git remote add origin https://github.com/<你的用户名>/omniformos.git

git push -u origin main
```

**推送前自查**：

```powershell
git count-objects -vH     # 约 47 MiB，Gitee 单文件限 100MB，全部可推
git log --oneline | Measure-Object -Line   # 应为 20
```

- 确认远端打开后能看到：README（含 ⚡10 分钟复现指南）、`.env.example`、`docs/competition/`（AI 对话快照、技术文档 PDF、录制脚本、字幕）
- 推完用**无痕浏览器**打开仓库链接确认公开可访问（评审就是这么看的）

## 第 3 步：上传桌面安装包（可选但建议）

现成产物：`output/desktop/OmniFormOS-Desktop-1.2.0-x64-Setup.exe`

- 传网盘（蓝奏云/百度网盘/阿里云盘均可），把链接和提取码写进提交说明
- 若文件被网盘误报，可压缩成 zip 再传；不要改文件名里的版本号
- 评审按 README 源码构建也可以：`npm install → npm run desktop:build`

## 第 4 步：最终提交物打包

按大赛 2.1-2.3 逐项对表（逐项验证后再确认）：

| 大赛要求 | 提交物 | 状态 |
|---|---|---|
| 2.1 公开代码仓库 | Gitee/GitHub 链接（保留历史并附集中入库说明） | ⬜ 待 push |

| 2.2 README 十分钟复现 | 仓库内 README + `.env.example` | ✅ |

| 2.3 技术文档 ≤30 页 | `docs/competition/OmniFormOS技术文档-v1.2.0.pdf`（17 页） | ✅ |
| 桌面版可执行 | 1.2.0 Setup.exe + 网盘链接 | ⬜ 待上传 |

**提交动作**（按大赛通知的提交渠道执行）：

1. 视频文件 + 技术文档 PDF：按大赛要求的渠道上传（表单附件 / 网盘 / 邮件）
2. 提交文字里写明：仓库链接、网盘链接（若有）、一句话作品简介
3. 提交前最后跑一遍验收命令，确保仓库当前状态可复现：

```powershell
git clone <你的仓库地址> test-clone
cd test-clone
npm install
npm run check
npm test
npm run dev     # 打开 http://127.0.0.1:3100 能看到工作区
```

> 用 `test-clone` 模拟评审第一次拿到仓库：这一步如果失败，说明有依赖 git 历史之外的本地文件，必须在提交前修掉。
