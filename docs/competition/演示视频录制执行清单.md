## 三、★2 分钟 AI 协同怎么录（最容易扣分的部分）

评审要看到的是：**你输入 Prompt → AI 输出 → 你判断 → 你反馈 → 修好**这一整条闭环，而不是"我用了 AI"。

### 场景 A（80 秒）：Prompt 驱动生成「设置 9 大栏目」

1. **0-10s** 打开 WorkBuddy 对话窗口，展示你真实输入的 Prompt（原文可用下面这段，来自本项目真实开发对话）：

   > 按表格重构设置页，分 9 大栏目：通用与外观 / AI 模型与 API / 账户与安全 / 工作区与数据 / 模块设置 / 集成与自动化 / 桌面应用 / 运行与诊断 / 关于与更新。左侧独立滚动导航，右侧内容双栏，不要密集。

2. **10-60s** 让 AI 改代码，镜头跟着滚动看它改 `omni-auth.js` 的 `SET_TABS` 数组与 `setTab` 状态；可 1.5x 加速。
3. **60-80s** 切到应用窗口 `Ctrl+R`，展示改前（单页长列表）vs 改后（9 栏 + 双栏）对比。

**口播**："我没有说'把设置页做好看点'，而是先给栏目表、再给布局约束。规范先行，AI 一次成型，不用反复返工。"

### 场景 B（65 秒）：引导 AI 修顽固 Bug「深色主题红绿灯变色」

1. **0-10s** 展示 Bug 截图：深色主题下红黄绿三个窗口按钮全变成蓝色。
2. **10-35s** 展示你的 Prompt：

   > 深色主题下红绿灯没有颜色了，其他按钮正常。查一下是不是全局样式覆盖了。

   AI 定位过程要露出来：`dark-fix.css` 里 `button{...!important}` 把 `#ff5f57/#febc2e/#28c840` 全覆盖 → 提升到专用选择器优先级。
3. **35-55s** 切应用窗口刷新，红绿灯恢复；再顺手展示侧边栏配色、输入框底色两个同类问题一起修好。
4. **55-65s** 一句总结："一个 Bug 往往是一类问题，我让 AI 顺着根因把同类场景全排查了一遍。"

### 录法二选一

- **方案 1（推荐，真实感强）**：现场重跑一次，用上面两段 Prompt 让 AI 真改一遍。注意提前跑通一次，避免现场等待过长；等待段落在剪辑时压到 1.5x。
- **方案 2（稳）**：录 WorkBuddy 的历史对话回放（本项目对话已归档在 `docs/competition/AI对话历史快照.md`，可对照展示）+ 文件改动前后的 diff，同样算"复现"。
