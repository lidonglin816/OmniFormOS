## 本次实现

| 方向 | Before | After |
| --- | --- | --- |
| 统一编辑环境 | 页面与基础组件编辑 | 页面、图层、组件、资源、属性、事件、设计变量和响应式预览统一操作 |

| 事件 | 基础操作 | 六类触发器、八类动作，条件、错误分支、输入映射及执行日志 |
| AI 修改 | 页面生成 | 组件/页面/应用作用域约束、修改差异确认和并发修改保护 |
| 模板 | 页面模板 | 六套校园蓝图生成三页应用、真实空表、表单、管理表格和状态图表 |
| 测试 | 预览 | 只读设计预览、独立内存数据副本测试、检查报告、日志和重置 |

## 当前边界

- 事件编辑器提供结构化 JSON 编辑、可视摘要与校验，尚非自由拖拽节点画布。
- 外部 AI 模型未配置，未宣称完成在线模型实测；可手动创建、编辑、绑定数据和发布。AI 接口支持受限页面修改，尚未自动生成完整数据库、权限及审批系统。
- 提供组件协议及本地组件复用，尚不支持任意 React 代码托管或在线组件市场。
- 测试中心是静态检查加隔离运行日志，尚非完整浏览器自动化平台。内存副本按需复制数据源，最多保留 20 个应用、每个 200 条服务端日志；版本变化、重置或服务重启会清除。测试模式禁用业务嵌入和外部 AI 调用。
- 数据表最多载入 500 条后在客户端搜索分页，并明确显示上限；图表按全部授权记录计算。字段编辑支持常用类型，尚非完整附件、多选和关系字段编辑器。
- 权限包括工作区会话和公开访问范围，尚非完整多用户账号与细粒度角色分配系统。
- 表单可启动已配置审批，但审批完成不会自动回写 TableMind 状态；尚无任意 AI/审批事件节点编排。
- 六套校园模板是可继续配置的通用三页蓝图，尚非六套完整行业系统。
- 网址目前为本机服务；尚未完成公网部署、React 源码导出及多人协作。

## 启动与备份

主服务须保持运行。可双击项目根目录 `Start-OmniForm.cmd`，或执行 `npm run start:workspace`。已运行时无需重复启动。

启动器使用现有八个数据库路径，不创建替代工作区。升级前备份：`artifacts/before-appcanvas4.ofbackup`；备份不包含模型密钥或浏览器存储。验收服务使用单独的 `artifacts/canvas4-qa-*.sqlite`，未覆盖主工作区。
