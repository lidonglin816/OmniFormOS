# AppCanvas 编辑器布局与交互重构

本次仅调整 AppCanvas 编辑器及其共用组件渲染器，不增加新的业务系统。保留现有应用、数据源、版本、发布入口以及其他七个模块。

## 布局

- 编辑器固定在 100dvh 内，56px 顶部栏；外层禁止滚动。
- 左侧默认 230px、可调整 220–260px；右侧默认 280px、可调整 260–320px；两侧可收起并分别滚动。
- 中央画布单独滚动，桌面逻辑宽度 1440px，平板 768px，手机 390px。默认适应窗口，支持 50%、75%、100%、125% 和居中。
- 页面、设备与预览分别记忆滚动位置和缩放模式；数据加载时暂停滚动记忆并关闭浏览器滚动锚定，避免数据表加载后意外跳动。
- 全屏运行预览完全移除两侧编辑面板、选中框、图层操作与悬浮工具栏；保留退出预览入口。

## 组件操作

- 页面具有 Header、Main、Footer 区域标识；复用容器、分栏和栅格，增加 Section 区块。
- 组件库分组可折叠；拖拽时显示目标之前、之后或容器内部的指示线/边框及宽度；接近画布边缘时自动滚动。
- 图层树显示真实嵌套层级，点击定位并滚动到组件。
- 选中工具栏提供拖动、复制、上下移动、隐藏、锁定与删除。
- 双击标题、描述和文本可直接编辑；Escape 取消，失焦提交；修改进入撤销记录并自动保存。
- 重复横幅及多个未配置按钮仅提示，可定位或保留，不自动删除。
- 一键整理对连续业务组件进行两栏分组、统一间距，保留原组件 ID、内容、顺序和数据绑定；移动端切换单栏，可撤销。

## 属性与保存

- 内容、布局、样式、数据、交互五个标签；权限、显示和锁定保留在布局标签中。
- 根据组件类型展示相关字段，减少无关表单和留白。
- 属性输入实时更新画布，避免重新渲染整个编辑器；保留输入焦点、页面滚动和缩放。
- 布局和样式独立合并到 Schema；移动端样式独立覆盖，不清除已设颜色或数据绑定。
- 自动保存区分已保存、正在保存、有未保存更改和失败；未保存时关闭页面会触发浏览器提示。
- 快捷键：Ctrl/Cmd+Z 撤销、Ctrl+Y 或 Ctrl/Cmd+Shift+Z 重做、Ctrl/Cmd+C/V 复制粘贴、Ctrl/Cmd+D 复制组件、Delete/Backspace 删除、Ctrl/Cmd+S 保存；输入框、文本编辑和弹窗不拦截其原有快捷键。

## 验证结果

- 41 个组件的临时压力页面：视口和文档高度均为 720px；编辑器高度 720px，桌面画布自身内容高度 2337px，外层没有超长滚动。
- 平板画布内容高度 4338px，手机内容高度 6279px，均保持中央画布内独立滚动。
- 页面切换前后均保留 75% 缩放和 scrollTop=1542。
- 预览模式下左右面板数为零，选中工具栏数为零，文档高度仍为 720px。
- 浏览器验证：图层定位、实时属性、双击编辑、指定位置插入、拖动排序、复制工具栏、Delete、Ctrl+Z、Ctrl+Y、重复提示及保留内容的布局整理。
- 原生复制粘贴已实现，快捷键分派有单元测试；浏览器自动化的虚拟剪贴板限制使完整原生剪贴板往返未能自动验收。
- 111 项测试通过，语法检查和构建通过。临时测试应用已移除；清理前后两个原有应用的完整配置以及 TableMind、LabForm、FlowForm 数据一致。
- 浏览器会话重置后，工具安全策略阻止读取其内部错误页，因此没有补拍最终截图；本地 HTTP 首页已验证返回 200。
