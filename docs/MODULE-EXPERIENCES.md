# 六个模块的布局差异化

针对截图中“标题、标签、工具条、宣传语、统计条”重复堆叠的问题，本轮将辅助工具收进顶栏，缩短模块标题区。已确认的网站首页没有修改；现有数据、模块事件、API 和保存流程继续使用原实现。

| 模块 | 主体结构 | 可操作的显示切换 |
| --- | --- | --- |
| ExamCraft | 纵向测评导航、试卷卡架、暖色待阅卷栏 | 卡架／清单 |
| FlowForm | 左侧运行指标、中心流程、旁侧审批动态 | 运行总览／待办优先 |
| DocMorph | 左侧处理队列、右侧文档导入台 | 处理队列／文档卡片 |
| AdaptForm | 表单目录、点阵规则舞台、设备式填写预览 | 规则优先／填写优先 |
| TableMind | 紧凑工具栏、资源目录和表格一体框架 | 显示目录／展开表格 |
| LabForm | 主曲线、侧面仪表指标、研究档案与记录簿 | 曲线优先／记录优先 |

显示偏好保存在页面会话内，模块重绘后保留，刷新后重置。不写入项目数据库。收起平台导航后保留浮动退出按钮和 Escape 退出。

实现文件：`public/module-experiences.js`、`public/module-experiences.css`，由现有工作区初始化逻辑加载。
