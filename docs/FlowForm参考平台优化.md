# FlowForm 参考平台优化

2026-10-23。在既有动态表单、共享申请、会签、退回、审批、隔离测试及八类图表基础上增量优化。

## 本轮实现

| 参考方向 | 实现 | 使用入口 |
| --- | --- | --- |
| n8n 历史执行调试 | 选择原申请版本或当前流程草稿，使用材料做隔离重放；检查申请与流程版本冲突 | 申请详情 → 隔离重放 / 调试 |
| 飞书审批、简道云流转状态 | 每个节点显示已流转、处理中、待补充、异常或未流转；点击展开事件、配置及后续路由 | 申请详情 → 流转图与节点检查 |
| Dify 节点追踪 | 新执行条件保留输入、期望值、匹配结果和实际 yes/no 路由；数据节点记录修改前后值 | 条件节点 → 查看本次输入与判断结果 |
| Make 条件路由 | 检查器明确列出满足、不满足、下一步对应的目标节点 | 流转检查、AI 蓝图 |
| Zapier Canvas 业务规划 | AI 生成候选展示节点、字段、线路的新增/调整/移除数量及可展开蓝图；三类校园需求快捷填入 | AI 流程设计 |
| 宜搭、简道云表单流程一体化 | 字段编辑器提示该字段被多少个条件节点引用 | 发布与集成 → 编辑动态表单 |
| Baserow 测试与发布区分 | 重放保存为隔离测试，复用现有测试管理和统计隔离；保留发布快照与 TableMind 原数据授权 | 隔离测试、发布与集成 |
| 审批瓶颈分析 | 运行分析新增待办明细，显示当前节点、待审角色、等待分钟、超时，支持打开对应申请 | 运行分析 → 待办瓶颈 |

## 行为和边界

- 重放仅向本机流程创建者开放，申请人及共享审核令牌不能调用；后端核验原申请 revision 和选定流程 revision。
- 新申请保留提交时数据快照，条件事件保留当时输入。修改后数据不会反向改变原判断记录。
- 旧记录没有提交快照时明确显示“历史记录保留值”，不声称能恢复原始输入；旧事件没有输入记录时不推算历史输入。
- 重放自动模拟审批通过并跳过延迟，只验证流程路径，不验证人工审批决策和真实等待时间。
- 重放仅写入校园隔离测试记录和审计；不改变原申请、正式审批结果、真实通知或 TableMind 成绩源。
- 待办瓶颈仅包含正式 pending / waiting 记录，使用与运行分析相同的流程、状态、类型、日期筛选，按超时及等待时间排序。
- 蓝图预览仅是候选，确认保存后仍为草稿；不会自动发布或改变正在运行的申请。
- 新流转检查采用响应式可展开节点卡片和路由目标，专业拖拽及连线编辑继续复用现有 React Flow 画布。
- 本轮未接入外部网站账号、邮件、飞书或钉钉消息；不把本地站内通知冒充第三方发送。
- 真实 AI 生成仍需配置模型服务。

## 验证

184 项测试通过。新增覆盖条件快照、输入不可回写、待办筛选、正式与测试隔离、HTML 转义、稳定 ID 差异、重放权限、申请与流程并发版本、原版本与草稿版本、字段不兼容、正式记录和通知不变。语法检查与资源构建通过。本轮浏览器自动化接口不可用，未声称完成浏览器视觉验收；已验证渲染函数、接口和构建。
