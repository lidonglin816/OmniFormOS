# 校园、生活与工作应用提示词

万能公式：建立一个 XX 系统，角色有管理员和普通用户，支持功能1、功能2、功能3。

模板生成可编辑的数据实体、字段、关联和页面。审批执行需要在 FlowForm 配置，角色安全隔离不能仅依靠蓝图配置；抽奖模板管理名单和中奖记录，不包含随机抽奖引擎。

## 校园

### 学生信息

建立一个学生信息系统，角色：管理员、普通用户。支持学生档案、班级维护、联系方式管理；管理员维护配置和全部记录，普通用户提交与查看自己的记录。支持搜索、筛选和导出。

### 实验室管理

建立一个实验室管理系统，角色：管理员、普通用户。支持设备登记、借用申请、实验记录；借用提交→实验室管理员审核→登记归还；管理员维护配置和全部记录，普通用户提交与查看自己的记录。支持搜索、筛选和导出。

### 社团报名

建立一个社团报名系统，角色：管理员、普通用户。支持社团资料、成员报名、报名审核；管理员维护配置和全部记录，普通用户提交与查看自己的记录。支持搜索、筛选和导出。

### 宿舍报修

建立一个宿舍报修系统，角色：管理员、普通用户。支持楼栋房间、故障描述、维修派单、处理状态；学生提交→宿管登记→维修人员处理→学生确认；管理员维护配置和全部记录，普通用户提交与查看自己的记录。支持搜索、筛选和导出。

### 课堂签到

建立一个课堂签到系统，角色：管理员、普通用户。支持课程安排、学生签到、缺勤记录；管理员维护配置和全部记录，普通用户提交与查看自己的记录。支持搜索、筛选和导出。

### 成绩管理

建立一个成绩管理系统，角色：管理员、普通用户。支持课程成绩录入、考试成绩查询、成绩导出；管理员维护配置和全部记录，普通用户提交与查看自己的记录。支持搜索、筛选和导出。

### 校园竞赛管理

建立一个校园竞赛管理系统，角色：管理员、普通用户。支持团队报名、作品提交和参赛审核；管理员维护配置和全部记录，普通用户提交与查看自己的记录。支持搜索、筛选和导出。
