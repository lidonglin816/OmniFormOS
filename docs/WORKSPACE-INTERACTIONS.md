## 可操作的交互

- 内部页面顶部“搜索与切换”或 Ctrl / Cmd + K：搜索当前页面现有视图、可见项目和模块。支持方向键、Enter、Escape、无结果提示及关闭后焦点恢复。
- 工作区“专注模式”：收起平台导航，扩大内容区域；按钮或 Escape 退出。AppCanvas 使用原有沉浸式编辑器。
- “界面选项”：切换舒适／紧凑间距，并控制当前可用辅助面板。间距偏好只保存在当前浏览器会话。
- 可折叠的上下文面板：FormPilot 属性、AdaptForm 实时预览、DocMorph 文档原件、TableMind 资源目录、LabForm 档案和曲线配置。
- 现有拖拽增加来源与目标提示，不接管原有排序、规则或数据更新逻辑。

## 后续动效更新（2026-10-21）

新增 `workspace-motion.js` 与 `workspace-motion.css`：内部按钮指针按下反馈、160ms 工作区内容淡入、180ms 标签切换、240ms 数据侧栏展开，以及卡片与组件选中反馈。仅装饰现有交互，不触发业务操作，不延迟事件，不修改数据。键盘发起的切换即时完成；连续操作取消旧动画；尊重系统减少动态效果设置。首页样式哈希与上述记录一致。

本次联网检索已成功，参考 Motion 官方的视图过渡说明 https://motion.dev/docs/animate-view 和减少动态效果指南 https://motion.dev/docs/react-use-reduced-motion 。实现采用原生 CSS / Web Animations API，无新增运行依赖。113 项既有自动化测试及语法检查通过；屏幕级动效复核仍未完成，不能据此宣称已验证所有动画观感。

## 物理动效

AdaptForm 字段通过已有移动按钮／拖放重排后，捕捉前后真实坐标执行 FLIP，再以弹簧积分归位。内部导航选中高亮沿选中位置弹簧移动，标签文字不移动。弹簧使用质量 1、刚度 100、阻尼 10；后台恢复时限制积分步长，元素卸载、键盘输入及减少动态效果变更会清理动画。新增物理模型收敛、初速度、后台暂停及坐标差测试，总计 115 项测试通过。首页两个样式文件哈希仍一致。尚未完成浏览器视觉复核；未实现惯性拖动、共享详情过渡、磁性按钮、粒子或滚动叙事。

## 共享标题与面板衔接

FormPilot 项目卡片打开现有编辑器时，使用 View Transitions API 将项目标题衔接到编辑器标题。不支持 API、键盘触发或减少动态效果时即时执行原有打开逻辑；快照失败不重复操作；离开模块后不执行过期的打开操作。仅对标题截图，避免将整个表单或工作台拉伸。

辅助面板的折叠按钮通过 FLIP 为相邻区域提供位置过渡；相同区域连续操作保留弹簧速度，并从当前可见位置接续。布局尺寸即时生效，不逐帧计算宽高。新增共享过渡的降级、恰好一次执行和过期动作测试，总计 118 项测试通过。浏览器视觉复核仍未完成。
