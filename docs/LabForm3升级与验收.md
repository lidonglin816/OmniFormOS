## 平台优势的落地方式

| 参考 | Before | After |
| --- | --- | --- |
| OriginPro | 基础科学曲线 | Plotly 工作室：真实散点、多曲线、拟合、误差棒、残差、近似置信带和 PNG/SVG 导出 |
| SciNote | 首页优先展示当前曲线 | 项目工作台、四个创建入口、搜索、真实项目统计与最近实验 |
| LabArchives | 记录集中在数据表及报告 | 独立电子记录本，记录课程、小组、观察、条件、材料、附件及版本 |
| Plotly / JupyterLab | 结果可查看，但缺少独立复算交付物 | 版本化计算配方，保留原始行 ID、参数、模型、公式、中间值，可用固定算法独立复算 |
| eLabNext / Benchling | 仪器文本与手工版本 | 记录仪器编号、校准与材料；保存前自动留档，最近 30 个版本，恢复前再次留档 |
| phyphox | 文件导入入口 | 独立采集中心、来源分组及会话保护的批次接口；明确展示硬件未连接状态 |

以上是适合当前项目的功能取舍，并未复制这些产品的品牌、素材或专有代码。

## 本次新增与修复

- 十个功能空间：工作台、AI 创建、电子记录本、实验数据、采集中心、科学计算、科学绘图、AI 分析、报告、模板与管理。
- 共 14 套空表模板，覆盖要求中的十类课程，并新增霍尔四向测量结构。四向抵消公式必须根据实际接线约定核对，默认参数可修改，不视为实测数据。
- 不确定度预算：样本标准差、标准误、A/B 类、合成、扩展不确定度、分布与覆盖因子。单次测量不报告虚假的零 A 类不确定度。
- 霍尔系数检查电压/磁场单位，转换为 SI 后计算；可计入电流、厚度的标准不确定度，缺失项明确标注。不同量纲不能混画同一个 Y 轴。
- 新增分组描述性统计及配方导出/复算；统计范围、拟合范围和算法版本保留在依据中。
- CSV/JSON 导入保留原始文本精度，修改不会覆盖初次录入的原始值。移除数据仍可通过原始档案或历史恢复。
- 修复变量 ID 输入框遮蔽表单 ID 导致字段配置保存失败，以及 blur 重复写入可能引发版本冲突的问题。
- 修复空白被当作零、示波器统计未遵循所选分组、分析期间数据变化后保存旧结论等问题。
- Lab API 纳入本机工作区会话保护；附件限制类型、大小、数量；设备批次拒绝未知变量及计算列写入。
- 图表按需加载。为兼容内置浏览器，PNG 使用同一 SVG 在本机转换；拒绝外部图像、脚本与非固定画布。文件通过受会话保护的临时 HTTP 链接下载，链接 10 分钟过期，服务重启后失效。

## 范围与待完善项

- 保留并复用现有 PDF/DOCX 指导书解析、真实 AI 请求及人工确认流程。没有配置模型时明确报错，不冒充 AI。自动测试使用模拟兼容协议服务，本轮未验收真实外部模型。
- 确定性引擎仍使用受控 JavaScript 算法，不执行任意 Python/JavaScript。线性与多项式使用 QR；指数采用对数域假设；RC 为带偏置指数的固定算法。未实现通用非线性模型或符号推导。
- 近似 95% 均值置信带使用正态近似，不是预测区间；k=2 不自动保证 95% 覆盖概率。重复测量预算必须由用户选择同一被测量及条件，不应对扫频/扫描磁场数据直接解释重复性。
- 电子记录本为结构化文本、图片及附件，报告保留轻量 Markdown 编辑；未实现完整自由块编辑器、Word 数学公式排版或 LaTeX 公式编辑器。
- PDF 仍为浏览器打印/另存为 PDF，不是服务端自动生成 PDF。
- 串口、蓝牙、phyphox 局域网 API、连续实时波形协议未实现。可运行路径是文件导入及手动确认的批次接口，页面不显示虚假连接状态。
- 教学方面记录课程与小组，保留现有跨模块提交/审批入口；没有新增完整的教师发布、学生账号隔离和评分系统，也没有通过角色下拉框授予教师权限。
- 复用原有跨模块来源关联入口，未宣称所有七模块均完成自动编排或实时双向同步。大型数据表虚拟化、多人实时协作及高级科研统计仍待扩展。
