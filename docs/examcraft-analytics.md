# ExamCraft 考试结果分析中心

入口：启动 `npm start`，打开 `http://127.0.0.1:3000/#exam?view=analytics`，或在 ExamCraft 点击“学情分析”。现有题库、试卷和正式成绩保留。

## 已实现

- 白紫色响应式页面：8 个统计卡、11 类 ECharts 图表、答卷明细、基于证据的学习建议。
- 图表：成绩分布、考试趋势、知识点正确率、班级×知识点热力图、题型得分率、试题正确率排行、个人雷达图、难度散点、耗时分布、参与趋势、班级对比。已测维度少于三个时，雷达图改为已有维度柱状图，不补造维度。
- 按考试、试卷、班级、考生、时间、题型、知识点筛选。分数段及其他图表选择会传入后端答卷 ID 范围，使统计、报告和导出保持一致；可“清除图表筛选”。点击知识点筛选关联题目，点击题目打开实际作答详情，明细行可高亮关联图表。
- 每 10 秒检查变化。无变化不重绘编辑中的筛选表单；评分或范围改变后，旧 AI 报告失效。
- 图表 PNG、Excel/CSV 成绩明细、可打印报告；PDF 通过浏览器打印中的“另存为 PDF”输出。报告展示筛选条件、生成时间及统计依据。
- 发布考试的考生名单支持 `编号,姓名,班级`（班级可省略）。
- 考生提交后可查看并打印自己的学习报告。服务端逐次校验答卷 Bearer 令牌；不会因为同名或相同编号而扩张到其他未授权考试。教师端可在已有管理权限内比较同一编号的历史考试。匿名考生的跨考试统一身份尚未建立，历史报告需分别通过对应考试链接访问。
- 本机工作台免密码自动建立 HttpOnly 会话；远程请求不能使用本机免登录参数，原有管理接口继续要求会话。管理 cookie 路径覆盖 `/api`，允许 TableMind 复用同一授权。

## 统一数据口径

`src/exam-analytics.mjs` 是服务端统计入口。浏览器接收后端指标、图表序列与个人能力汇总，不自行生成成绩统计。

- 参考人数按真实开始的答卷数计，同一考试邀请恢复原答卷；不同考试分别计入。
- 未交卷、待批阅、缺考分开显示；已评分但评分缺失或满分无效的记录不纳入有效成绩。
- 平均、最高、最低及趋势均使用得分率，允许不同满分试卷比较；及格率使用各试卷的及格线。
- 正确率 = 获得满分的作答数 / 已评分作答数；得分率 = 总得分 / 对应满分，二者明确区分。
- 题型、知识点筛选时按选中题目重新计算。平均耗时使用提交时间和开始时间完整的已交卷答卷。
- 考勤来自发布名单，日期和题型筛选不将已参加者误判为缺考；考勤区另行说明名单范围。
- 少于 5 份已评分样本提示仅作描述性参考。无数据的成绩指标为 `null`，不伪装为零分或满分。

## AI 与 TableMind

AI 配置沿用 `.env.example` 中的 `OMNIFORM_AI_BASE_URL`、`OMNIFORM_AI_API_KEY`、`OMNIFORM_AI_MODEL`。未配置时明确提示，规则诊断仍可使用。AI 请求仅包含当前筛选的服务端统计，不发送姓名、答卷原文、考生选项名单或个人画像 ID。AI 建议附加在确定性统计依据之后，不能替代评分结果。

点击“授权 TableMind 实时分析”后，TableMind 在读取时注入 `examcraft_live` 只读数据表，直接读取 ExamCraft 原始状态；不持久化一套独立成绩。评分变更会体现在下一次数据读取中。启用期间 TableMind API 继承 ExamCraft 管理会话检查，禁止修改、清洗、覆写和公开发布成绩源；授权可撤销。实时成绩查询的记录输出不保存到查询历史。

## 验证

- `npm run check`：语法检查。
- `npm test`：包含统计边界、人工复核、权限隔离、CSV/Excel、实时数据源与撤销、AI 请求证据及报告指纹等测试。
- `node scripts/build-exam.mjs`：构建本地 ECharts 和数学公式依赖。
- `scripts/verify-exam-analytics.mjs`：仅针对 `127.0.0.1:3100` 的独立验收实例，通过发布→开始→提交→人工复核的实际 API 流程产生测试答卷。先用 `PORT=3100`、`EXAM_DB_PATH=artifacts/exam-analytics-ui.sqlite` 启动实例，禁止将验收数据写入正式数据库。测试名称明确标注“非正式教学数据”。

浏览器验证了免登录入口、空数据、真实提交后自动刷新、图表全屏及点击分数段筛出对应实际答卷。
