# LabForm

LabForm 是 OmniFormOS 的第 7 个模块，面向工科科研实验的数据记录、计算、分析与报告归档。

当前霍尔效应模板包含恒定电流、样品厚度、实验温度等带单位参数。每个磁场点记录三次霍尔电压，公式引擎计算平均值、样本标准差、线性回归、拟合优度、斜率标准不确定度及霍尔系数，并绘制带误差棒的关系曲线。

保存版本时会深拷贝实验参数、原始数据和计算结果，后续修改不会改变历史快照。报告中心汇总实验目的、条件、公式、结果、不确定度和实验记录，可导出 JSON。

数学计算由确定性公式完成；文字解释为本地规则提示。当前原型没有仪器连接、研究身份认证、电子签名或正式实验室质量体系，科研结论仍需研究人员复核实验设计、仪器校准、量纲和有效数字。
