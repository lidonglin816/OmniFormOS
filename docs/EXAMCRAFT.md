# ExamCraft v0.3 · 智能考试与测评工厂

## 入口与流程

启动项目后访问 `http://127.0.0.1:3000/#exam`，或点击侧栏 ExamCraft。

1. **大纲与来源**：粘贴或读取 UTF-8 TXT 大纲，每行使用「知识点：事实说明」。也可导入只有标题的大纲用于覆盖分析。
2. **规则出题**：选择大纲及单选、多选、判断、简答题型。每个含事实说明的知识点按所选题型各生成一题。生成直接引用资料内容，需人工校对；未接入大语言模型。
3. **题库编辑**：调整题干、选项、答案、题型、难度、分值、知识点、来源位置、解析及简答题关键词。右侧即时显示教师预览。草稿本地保留，点击保存后才更新正式题库。
4. **试卷工坊**：创建草稿，从题库添加题目；拖动或用上下按钮排序，调整分值、名称、建议时长与通过线。题目以独立快照加入试卷。
5. **本地发布**：发布后试卷不可直接修改，可复制为新草稿。发布仅对当前浏览器存储生效。
6. **答题**：填写答题人名称，选择或输入答案。答题进度本地保存，刷新恢复；未提交答卷也可从测评入口继续。
7. **评分**：客观题自动评分；已作答简答题按关键词命中比例提供建议，需人工输入并确认最终分数。
8. **成绩分析**：查看真实提交答卷、待评分数量、平均得分率、通过率和个人知识点得分。可导出试卷、成绩 JSON，或用平台右上角导出完整备份。

## 题库导入格式

支持 JSON 数组，或 `{ "questions": [...] }`。页面提供可下载示例。答案采用零起始选项序号，`single` 和 `boolean` 只能选一个，`multiple` 可有多个；`short` 使用文本答案和关键词数组。

```json
{
  "questions": [
    {
      "type": "single",
      "stem": "必填规则的作用是什么？",
      "options": ["阻止必要信息缺失", "自动删除数据"],
      "answer": [0],
      "points": 5,
      "difficulty": 2,
      "topic": "字段校验",
      "sourceRef": "培训手册，第 1 节",
      "explanation": "提交前检查必要字段。"
    },
    {
      "type": "short",
      "stem": "权限校验应该在哪里执行？",
      "answer": "在服务端进行身份和操作授权校验。",
      "keywords": ["服务端", "身份", "授权"],
      "points": 10,
      "difficulty": 3,
      "topic": "权限控制",
      "sourceRef": "培训手册，第 2 节"
    }
  ]
}
```

判断题 `boolean` 固定使用 `options: ["正确", "错误"]`。`difficulty` 范围 1–5；单题分值大于 0 且不超过 100。整批题目校验成功才写入，单次最多 200 题，读取文件最多 2 MB。导入时以所填来源名称建立原始资料快照，并为题目生成新 ID。

## 评分约定

- 单选、判断、多选都采用精确答案匹配，全对得分，否则 0 分；多选没有漏选部分分。
- 未作答题目为 0 分。未作答简答题直接记 0；已作答简答题进入待批。
- 关键词建议按文字命中比例计算，不理解语义，也不自动成为最终成绩。人工确认分数必须在 0 和该题满分之间。
- 待批答卷显示当前已确认得分，未批部分暂计 0，暂不判定通过，也不计入看板平均分和通过率。
- 平均得分率为每份已评分答卷的得分百分比的平均值；覆盖分析显示当前资料库所有大纲知识点及试卷额外知识点。
- 答卷启动时保存完整试卷快照；后续题库编辑、试卷复制不会改写历史答卷。

## 嵌入 FormPilot

已发布试卷页点击「嵌入 FormPilot 应用」，选择现有应用。该应用的预览概览页会出现「培训与测评」入口，点击进入 `#exam?paper=<id>` 对应试卷。应用蓝图通过 `assessments` 保存关联，独立测评入口和业务应用入口使用同一份本地试卷。

## 数据与边界

数据保存在原有 `omniformos.v1` 工作空间的 `examcraft` 属性中：来源 `sources`、题库 `questions`、试卷 `papers`、答卷 `attempts`、编辑草稿 `drafts`。页签和当前题目、试卷、答卷使用 sessionStorage。

本地原型不提供正式考生/教师隔离、真实 AI、后端数据库、跨设备共享、倒计时强制收卷、防作弊、公开发布或独立网站打包。建议时长仅供参考。只支持 TXT 与 JSON 导入，没有 PDF/Word 文档解析或 OCR，也没有 Markdown/LaTeX 公式渲染。

题库及正确答案在浏览器端可见，适用于流程体验；正式考试需要服务端保存试卷和答案、身份认证及受控评分接口。导出备份当前用于保存原始数据，尚未实现整工作空间导入恢复。
