# 首页中央吉祥物背景

本次新增独立的 Hero 背景层；首页标题、AI 输入框、建议按钮、八张扇形卡片和原有交互没有调整。原 `homepage-light.css` 和 `creative-system.css` 文件哈希保持不变。八大业务模块代码没有因本次集成修改。

## 角色与展示

项目此前没有 3D 角色组件或 GLB/GLTF 文件。`src/hero-mascot.jsx` 按用户图片中的紫白外壳、深紫面罩、大眼、胸口与额头星标、耳罩、头部造型和星环建立程序化轻量模型。这是基于二维参考的 3D 近似，不是原图对应的原始精细建模资产。原图保存在 `public/assets/omniform-mascot-reference.png`，用作加载及无 WebGL 的静态降级。

Hero 的布局尺寸不变。模型容器桌面宽度 450–650px，根据 Hero 高度缩放相机以显示完整身体；手机容器 300×320px。实际角色显示高度服从现有 Hero 空间，不通过增大 Hero 改动首屏。透明度桌面 0.15、手机 0.10，直接设置在背景容器上，网格保持正常不透明材质与深度测试。浅色遮罩位于模型和前景之间，不使用模糊。

## 交互与性能

- React Three Fiber + Three.js，通过独立 bundle 按需加载，仅首页挂载。
- 全局 `pointermove` 映射到头部水平 ±15°、垂直 ±10°、身体水平 ±3°；头部使用 Quaternion.slerp，瞳孔使用时间步长阻尼。
- 鼠标不改变模型整体横向位置；离开窗口恢复居中。
- `useFrame` 更新网格引用，不更新 React 高频状态；带轻微浮动、呼吸、眨眼和星环旋转。
- 透明 Canvas、pointer-events:none、aria-hidden、inert，DPR 限制 1–1.5。
- Hero 滚出视口、页面不可见时改为 demand 渲染；系统减少动态效果时静态显示。
- 路由离开后卸载 React/R3F 根节点与监听器。导入失败或渲染出错时保留静态图片。

## 验证

- 浏览器确认 `renderer=webgl`、桌面透明度 0.15、Canvas 不接收指针。
- 768px、390px 实测居中偏差不足 0.01px，无新增横向溢出，输入框中心命中输入框而非 Canvas。
- 滚出 Hero 后 `motion=paused`；离开首页后吉祥物 Canvas 数量为 0。
- 输入内容在首页锚点跳转后保留。
- 120 项自动化测试通过，包含鼠标方向、角度限制、阻尼帧率独立性测试；构建与语法检查通过。
- 无 WebGL 的专用硬件环境与系统减少动态效果设置未在本轮机器上强制切换；代码具备相应降级路径，不将静态图冒充运行中的 3D。

参考：React Three Fiber 官方 [Canvas](https://r3f.docs.pmnd.rs/api/canvas) 与 [Hooks](https://r3f.docs.pmnd.rs/api/hooks) 文档。

## 脸部特写调整

根据后续反馈，首页改为大幅面脸部背景：移除身体、手脚与身体星环的几何体，仅保留头部、面罩、双眼、耳罩与星形装饰。Canvas 扩展至 Hero 宽度，桌面高度为 Hero 的 180%，在现有 Hero 背景内形成近景构图，不改变首屏布局。静态降级也通过 CSS 显示参考图脸部，不显示身体。

头部跟随范围调整为水平 ±20°、垂直 ±12°；跟随阻尼速率从 5 提升到 12，眼睛独立使用速率 22。瞳孔位移从横向 0.075、纵向 0.055 提升到 0.14、0.11，回正仍采用较缓的速率 3。透明度与指针穿透策略保持不变。

## 分隔线手爪

在 Hero 与功能卡片之间的原有 `.gallery-caption` 分隔线上添加一对紫白 3D 手爪。掌心在线上，三根圆润手指及紫色指尖垂在线下；未恢复身体和手臂。独立锚定分隔线，不随头部转动或漂移。复用按需加载的同一 3D bundle，通过 React portal 管理独立的 demand Canvas，只在挂载与尺寸变化时绘制，离开首页一并卸载。

手爪容器为绝对定位、aria-hidden、inert、pointer-events:none，不改变原有文案、分隔线或卡片位置。桌面及 390px 手机已实测无新增横向溢出，无控制台错误，手爪不会截获点击。最终截图：`artifacts/homepage-face-with-paws.png`。

后续外观微调：手爪横向放大 45%、纵向放大 30%，从中心两侧的 22% 改为 25% 间距；增加紫白外壳与淡薰衣草内侧的大垂耳。面罩从深紫改为浅薰衣草色，保持页面原有浅色主题和鼠标追踪。手机手爪略向线下移动，以避开分隔线旁的说明文字。截图：`artifacts/homepage-big-paws-ears.png`。
