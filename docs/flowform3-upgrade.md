# FlowForm 3.0 校园审批与自动化升级

## 现有能力审查

升级前真实可用：SQLite 状态与迁移备份、React Flow 画布、节点连接与结构校验、条件和串行审批、驳回/退回/撤回/转交/加签、发布与版本恢复、独立模拟执行。

原有缺口：申请表只有金额/天数等通用输入；审批身份来自浏览器选项，不能作为共享身份；审批中心的部分筛选只是展示；没有受保护的校园申请入口、资源冲突检查、归还确认、材料管理和真实 ECharts 分析；“数据更新”节点实际上被转换为通知。

本次保留原始工作流 ID、历史定义及运行记录，新增校园运行时。旧引擎继续作为执行基础，其他模块和已有功能保留。升级前数据库另有一致性备份 `artifacts/flowform-before-3-1792581321619.sqlite`。

## 使用入口

本机页面：`http://127.0.0.1:3100/#flowform`。常规 `npm start` 默认端口仍是 3000。

- 我的事务：8 个可点击状态入口、流程档案、最近申请及可定位动态。
- 校园模板：12 类模板，另可从空白通用流程开始。点击模板生成可编辑的实际申请表与 Workflow。
- 申请与审批：草稿、搜索、状态及紧急筛选、材料详情、时间轴、审批意见、补充提交、撤回、附件下载和 CSV 导出。
- AI 设计：创建或修改候选 Schema，显示前后差异，服务端校验，确认才保存。未配置模型时明确提示，模板继续可用。
- 专业编辑器：复用 React Flow，保留连接、断线、自动布局、撤销重做、缩放、小地图、全屏、草稿与历史版本；增加表单、会签、数据更新、延迟、人工确认等节点及属性。
- 隔离测试：完整动态表单作为测试输入，确定性检查后执行真实状态机，展示条件结果和节点轨迹；延迟使用测试时钟推进，不等待真实时间。测试结果持久化但不进入正式统计。
- 运行分析：6 个真实指标、8 类 ECharts 图表，支持时间/流程/状态/申请类型筛选、PNG 和 CSV。没有数据时显示原因。
- 通知中心：站内消息持久化，支持已读/未读和关联申请。服务端周期检查审批超时、设备归还和预约到期。邮件未接入。
- 发布与集成：动态表单可视化编辑、条件规则高级配置、发布快照、分享与审核邀请、撤销授权、版本恢复、复制、归档、停用及模块事件绑定。

## 三个标杆场景

### 实验室设备借用

先登记实际设备；填写借用时间与用途，服务端检查日期及预约冲突；超过三天增加负责人复核。通过后显示已借出，申请人请求归还，管理员确认后状态为已结束并释放资源。提交中的申请也占用对应时间段，避免并发重复预订。

### 社团活动

活动信息、场地、人数、预算和策划附件；超过 2000 元增加学院复核。审核可退回补充材料，重新提交保留历史轨迹和申请 ID。

### 学生报销

姓名、编号、邮箱、用途、金额和票据；必填及金额范围严格校验。超过 1000 元进入财务二审。审批结果写入通知，可按范围导出包含金额、用途和附件文件名的 CSV。

其余模板包含请假、场地、志愿时长、奖学金、调课、报修、毕业材料、项目验收、竞赛。每种模板具备匹配的字段与基础审核；不需要金额分支的业务使用基础审核路径，避免把缺失金额默认为零冒充条件判断。

## 身份、数据与执行边界

- 本机创建者免登录，由本机引导接口建立 HttpOnly 管理会话。该入口仅接受回环地址。
- 申请入口令牌仅用于创建独立草稿；申请人获得自己的访问令牌，无法读取其他申请或执行审核。匿名入口含一次性算术验证和每 IP 请求频率限制。
- 审核邀请绑定一个流程与指定审核角色，有效期 30 天，可撤销；服务器忽略申请中的自报角色，按令牌和当前待办节点校验。
- 凭证哈希与有效期保存在同一个 SQLite 中的独立表，旧状态接口不返回这些凭证。
- 浏览器访问旧审批接口不能处理校园申请，避免通过旧角色参数绕过新权限。受信任的 FormPilot 服务内部调用仍需通过表单校验。
- 审批、资源检查、状态变化、事件消费和幂等记录使用 SQLite 事务。申请版本冲突返回 409；同一幂等标识用于不同内容会被拒绝。
- 附件最大 2 MB，限定 PDF/图片/TXT/DOCX/XLSX，按申请访问权限下载。文件以附件下载，不执行或嵌入上传内容。
- 并行节点采用多人会签、全部同意后继续；数据节点仅更新当前申请的标量字段，不执行脚本或任意外部写入；延迟节点持久化恢复时间，服务重启后继续检查。
- 当前服务器继续绑定 127.0.0.1，分享页面在当前本机服务中可访问。此升级没有额外部署外网服务。

## 跨模块连接

- FormPilot：保留 manager 审核适配器；连接 3.0 流程时可配置申请字段到实体字段的映射，服务端校验必填覆盖与实际提交。复杂多角色审批仍在 FlowForm 的专属审核页面处理。
- AdaptForm：导入已保存表单字段，保持字段 ID；自动匹配金额/预算条件，未能匹配时拒绝静默导入。也可授权表单提交事件，按字段映射触发正式申请。
- DocMorph：从已有文档或已复核表单生成 AI 候选流程，原始内容仅作为资料，不执行其中的指令，必须人工确认。
- ExamCraft：仅消费已完成评分且通过的真实答卷事件，保留试卷和答卷 ID。
- LabForm：消费指定实验项目的真实报告记录，保留项目与报告 ID。
- TableMind：授权后实时读取 `flowform_live`，不另存一份可编辑审批结果。权限继承 FlowForm 管理会话；禁止对实时表覆写、清洗和公开发布。
- AppCanvas：“审批流程”组件可嵌入申请及个人进度，或私有审核待办验证入口；审核密钥不写入公开组件。通用数据源排除校园私有实例与受保护的实时表，避免借其他模块绕过访问限制。

事件每 15 秒检查，也可手动同步；按绑定和来源记录 ID 去重。失败原因持久化，修正后可重试或停用绑定。跨模块材料仍需满足目标表单的必填与业务规则，不伪造缺失信息。

## 统计口径

仅使用 mode=live 的实际申请；测试与草稿不进入分析。通过率分母为已通过、已结束、已驳回；待补充材料、撤回及未决申请不伪装为审批失败或成功。没有已完成样本时通过率和平均耗时为空。节点耗时从真实 waiting 到 approve/reject/return 事件计算，状态转换元数据不重复计入事件统计。CSV 与页面使用相同权限及筛选范围。

- 核心文件：`src/flow-campus-service.mjs`、`public/flow-campus-model.js`、`public/flowform3.js`、`public/flow-campus-ui.js`、`public/flow-portal.js`。
