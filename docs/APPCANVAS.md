# AppCanvas

AppCanvas 是 OmniFormOS 第 8 个模块，也是八个子系统的最终组合与交付中心。

构建器包含页面树、组件面板、中央画布和属性面板。组件可点击或拖入画布，支持上下排序、移除、内容编辑、数据与功能绑定。内置组件覆盖标题横幅、指标、业务表单、数据表格、图表、审批待办、考试和操作按钮。

应用支持桌面、平板和手机预览，星云紫、深海蓝、自然绿三套主题。页面可以设置“全部成员”“管理员与编辑者”或“仅管理员”的原型访问范围。

本地发布会生成包含页面、组件、主题、绑定和权限的不可变快照；发布历史支持回滚。当前版本不会部署公网，也不提供真实身份鉴权，正式发布需要服务端存储、权限强制执行、构建产物和部署流水线。
