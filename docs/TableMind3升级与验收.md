## 已知范围与后续改进

1. 高级蓝图、公式、视图和全局筛选目前使用结构化 JSON 编辑，尚非完整图形化建模器。
2. 未配置外部 AI 服务时明确标注本地规则建议；外部模型请求路径已实现，但本轮未进行真实模型联网验收。分析报告只陈述可计算事实与样本依据，不推断因果。
3. 仪表盘以单张主表为范围，不支持任意跨源联表；ExamCraft 与 FlowForm 实时数据仍受原有权限控制。公开分享不允许暴露受保护的考试或审批数据。
4. 公网 API 为手动授权读取，尚无认证头配置和定时同步；安全规则由自动测试验证，本轮未调用外部 API。
5. 公式限受控数值运算，不执行任意 SQL、Python 或 JavaScript。
6. PDF 通过浏览器打印/另存为 PDF；并非服务端自动生成 PDF。支持事实分析 Markdown 报告。
7. 当前为本机工作区权限模型，未提供完整多人组织级 RBAC。网格每页 30 行，Excel 导入限制 5000 行、100 列，尚无大规模虚拟表格。
